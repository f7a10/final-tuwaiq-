# Spike 006: Homeowner Editor Session UX

## Question

Can Emad expose one understandable homeowner workflow over the validated geometry, planner, and AI-contract kernels without silent changes, stale previews, or ambiguous undo behavior?

## Scope

- Headless editor-session state machine before visual styling.
- Visible room → wall → door/window selection breadcrumb.
- One shared Preview path for direct, numeric, natural-language, and planner changes.
- Approved revision remains unchanged until an explicit approval action.
- Named atomic history operations with Undo and Redo.
- Draft freshness, confidence, warning, and blocking states.
- User-facing Arabic labels and recovery actions.
- No visual redesign in this spike; that starts only after the UX workflow is validated.
